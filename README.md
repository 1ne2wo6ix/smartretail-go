# SmartRetail Go – prototype

Interactive prototype of a checkout-free store app (ICT course project, Astana IT University, group IT-2611).
Sensors, gate and payment are **simulated** in the browser; no login and no personal data.

**Open:** https://1ne2wo6ix.github.io/smartretail-go/

Team: Amantay Alim, Shormanov Yerasyl, Omirzak Kuanyshbek.
